# Welcome

This is the **Celano Lab metro** working site — an internal hub for the
Nanoelectronics Metrology & Failure Analysis group at ASU.

The goal is simple: keep the notes, protocols, and small tools we build in one
place so the next person can pick up where we left off.

## What lives here

- **Docs** — protocols, SOPs, and lab notes. Anything worth writing down.
- **Tools** — small, focused utilities. First one is an image compare slider.

## How it is built

Pure static HTML, CSS, and JavaScript. No server, no build step, no install.
Push to a GitHub repo, turn on GitHub Pages, and everyone in the lab has the
link. See the README in the repo for details.
